# Отчёт по контрольной работе 2 (вариант 2)

## Выполнение требований

1.	Иерархия должна состоять минимум из трех классов.

    - Реализовано три класса: книга (родитель), комикс и учебник

2.	Базовый родительский класс должен быть абстрактным.

    - Класс `Book` абстрактный и содержит виртуальные методы

3.	В родительском классе необходимо определить минимум два полиморфных метода (не считая деструктора) и переопределить их в каждом классе-потомке.
    - Реализовано два виртуальных метода:
      - `setDefaultPrice()` - устанавливает стандартную цену книги
      - `setPriceWithDiscount()` - вызывает `setDefaultPrice()` а после применяет дополнительную скидку
    - Оба метода используют уникальные поля для своих классов. Формулы вычисления цен выдуманы наобум и не имеют логического смысла

4.	Создать один объект с помощью механизма позднего связывания, тип объекта должен выбирать пользователь.
    - Реализовано создание объекта по выбору пользователя и присваивание его к указателю на абстрактный класс `Book`

5.	С помощью раннего связывания создать по одному объекту для каждого не абстрактного класса.
    - Созданы два объекта классов `Comics` и `Textbook`

6.	Добавить static поле для подсчета созданных объектов. В программе вывести это количество.
    - Реализовано статическое поле `objCount` в родительском классе `Book`. Значение увеличивается при каждом вызове конструктора `Book` и выводится в конце программы
