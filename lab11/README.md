# Лабораторная работа 11

## **Лабораторное задание**

## Постановка задачи

Внести изменения в Лабораторную работу 10:
Реализовать обработку исключений. Не позволять создавать фигуры с отрицательными или нулевыми размерами и цилиндры с отрицательной или нулевой высотой. Генерировать и обрабатывать исключения минимум двух разных типов, одним из которых обязательно должно быть исключение-объект класса.

## Описание изменений

В коде уже были реализованы исключения типа `std::invalid argument`. Для соответствия заданию был добавлен собственный класс исключения `NotPositiveException` выбрасываемый когда не положительное значение присваивается полю которое должно быть положительным

## Компиляция и запуск

make runlab
